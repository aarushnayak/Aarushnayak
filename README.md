## 🚀 Featured Project

### Sales Data Analysis Dashboard

An interactive sales analytics project built with Python, pandas, SQLite, Streamlit, and Plotly.

- **[Open the live dashboard](https://aarush-sales-dashboard.streamlit.app/)**
- **[Explore the source code](https://github.com/aarushnayak/Sales-Data-Analysis)**
- **[View project documentation](https://github.com/aarushnayak/Sales-Data-Analysis#readme)**

**What it does**
- Tracks sales, profit, orders, units sold, and profit margin.
- Filters records by date, region, category, and product.
- Visualizes daily sales, regional performance, product sales, and category contribution.
- Flags suspicious data-quality records for review without silently changing the source CSV.
- Exports filtered data and flagged records as CSV files.
